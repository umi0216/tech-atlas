# 项目愿景：个人知识宇宙与开放知识图谱

状态：长期产品方向，依据维护者于 2026-10-21 明确提出的目标建立。此文描述目标与约束，不代表功能已经实现。

## 定位

以个人持续学习为入口，建设能够承载跨学科知识、学习路径、资料与实践证据的长期知识基础设施。以“人类图书馆”的尺度思考知识组织，以可验证的迭代建设功能。

目前的 TECH ATLAS 名称、仓库地址和已有七个技术领域继续保留；技术领域将成为整个知识宇宙的一部分。覆盖范围不封闭，未来可以自然延伸到数学、生命科学、物理、工程、人文、艺术等领域。

网站同时回答四个问题：这里有什么知识；知识如何相互联系；我现在理解到哪里；下一步如何学习和验证。

## 产品组成

| 组成 | 内容 | 主要用途 |
| --- | --- | --- |
| 知识地图 | 学科、分支、主题、概念及其有类型的关系 | 发现结构与跨学科联系 |
| 知识条目 | 定义、解释、公式、边界、实例、来源与修订记录 | 阅读和形成理解 |
| 资料目录 | 书籍、课程、论文、文章、实验和原始材料 | 回到来源继续学习 |
| 学习路径 | 目标、入口要求、步骤、练习与验收 | 从当前位置走向具体目标 |
| 个人记录 | 自评、学习事件、笔记、证据、复习和项目 | 记录真实成长 |
| 空间浏览 | 3D 总览、逐层展开、搜索定位与二维阅读界面 | 在规模与可读性之间连续切换 |

公共知识的完整性与个人的学习程度是两个独立维度。收录一个知识点不表示已经学习；打开条目不自动提升掌握等级；未评价不等于 L0。

## 体验方向

空间具有纵深、尺度变化、远近层次和持续但克制的环境运动。浩瀚感来自可探索的知识空间、跨学科关系和清楚的尺度变化。标题、正文、公式与操作控件始终易读。

从学科总览进入分支，再进入概念和内容。远景只显示聚合星系，靠近后逐层展开；用户能看见自己在哪里、如何返回、哪些内容已经加载。总览不铺满所有文字或全部连线。

3D 与目录、搜索、知识条目共享同一数据与选中状态。手机、键盘操作、减少动态效果和不支持 3D 的设备仍能完成阅读、搜索和编辑。点击与拖动优先于自动镜头运动。

## 数学展开示例

“数学 → 线性代数 → 线性映射 → 特征值 / 奇异值分解”可以作为一条浏览路径；同一概念也能被其他主题引用。例如奇异值分解可关联低秩近似，进而连接模型参数压缩的学习材料。

分类导航与学习顺序分别表达。某个主题属于线性代数，不表示它必然是所有模型课程的先修。学习路线根据目标、基础与验收要求建立。

上述内容仅为信息结构示例。正式收录需逐条补齐范围、解释、来源和必要的校验；不预填用户掌握度。

## 质量标准

- 知识：稳定标识、可追溯来源、明确关系语义、修订历史、可纠错；区分原始资料、作者解释和待核实内容。
- 学习：目标具体，练习可执行，验收有证据；允许多条路线、部分掌握和后续修正。
- 使用：先看清、找得到，再深入；3D 不能妨碍阅读、搜索和精确选择。
- 数据：开放格式、可导入导出、有备份与迁移方案；公开内容与个人私有记录有清楚边界。
- 工程：结构可扩展、改动可回归、版本可回退、部署可恢复；按实际规模优化。
- 内容权利：记录资料来源和许可；没有授权的材料优先保留索引、链接与原创摘要，发布前确认可公开范围。

## 部署与维护

GitHub Pages 继续服务当前静态版本和可分享的只读入口。可按需要使用维护者的 Linux 服务器、电脑与其他设备，承载同步、检索、内容管理、附件和计算任务。硬件不作为预设限制；每次新增常驻组件应说明它解决的实际问题、运行成本和恢复方法。

项目的长期目标不等于已经提供公共服务规模的可靠性。公开承诺应以实测、内容质量和实际运维能力为依据。现阶段优先把一个人的跨学科学习闭环做好，再逐步扩展协作与公共服务能力。

## 持续补充知识的流程

维护者提供材料或学习记录 → 区分公共知识、个人笔记和来源 → 提取候选条目及关系 → 检查重复、歧义和来源 → 人工修订 → 发布知识版本 → 连接个人记录与学习路径。

AI 可以辅助整理与提出关系；未经核验的内容保留待核实状态。知识扩展、界面效果与个人掌握度分别维护。
